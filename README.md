基于 **GLFW + GLM + Vulkan + Imgui** 的 C++ 渲染学习项目：绘制一个彩色三角形，着色器使用 **HLSL** 并在运行时通过 **DXC** 编译为 SPIR-V。

## 技术栈

| 组件 | 用途 |
| ---- | ---- |
| Vulkan API | 图形渲染 |
| GLFW 3.5.1 | 窗口管理 |
| GLM 1.0.3 | 数学库 |
| ImGui 1.92.9b | 已集成，预留 UI |

## 环境要求

- Windows
- Vulkan SDK（提供 `dxcompiler.lib` / `dxcompiler.dll`）
- CMake ≥ 4.3
- Visual Studio 2022+（MSVC，C++20）

一种底层、跨平台的图形与计算应用程序接口。
● 底层特性：Vulkan 的代码极其繁琐冗长！和 OpenGL 不同，它几乎需要手动处理每一项 GPU 流程。
● 跨平台特性：不同于 Direct3D，它可运行于任意平台！
● 但要在 macOS 和 iOS 上运行还需要额外适配工作：[https://moltengl.com/moltenvk/](https://moltengl.com/moltenvk/)
● 图形能力：用于在 GPU 上处理图形数据（包含在线渲染与离线渲染）。
● 计算能力：也可用于通用并行编程任务，作用类似 OpenCL。

● OpenGL（开放图形库）是跨平台图形 API。什么是 OpenGL？
● 可作为 Direct3D 的跨平台替代方案。
● 常被称作 “glNext”。在 Vulkan 正式公布前，业界一直期待这款 OpenGL 的续作。
● 据称其底层程度远高于 OpenGL 与 Direct3D 12。Vulkan API 于 2015 年公布，定位为 OpenGL 的继任者
● 由 Valve 通过 LunarG 团队提供支持；Vulkan 1.1 于 2018 年发布



● Vulkan 常被称作非常 “啰嗦”。
● 意思就是它需要写大量代码。
● 这不难理解！GPU 本身十分复杂，而 Vulkan 暴露了所有这些复杂能力。
● 为什么？因为更强的可控性 = 更大的优化空间！
● 绘制一个三角形最多可能需要 1000 行代码！
● 不过，大部分代码只是向 GPU 设置参数以及创建对象。
● 代码的逻辑本身非常简单。
